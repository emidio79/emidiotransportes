Landing Page - Transporte Escolar
Landing page responsiva desenvolvida em React e Tailwind CSS para divulgação de um serviço de transporte escolar, com foco em segurança, credibilidade e contato com pais e responsáveis.

Sobre o projeto
Este projeto foi criado para apresentar de forma profissional o trabalho realizado no transporte escolar, reunindo informações importantes como apresentação do serviço, diferenciais, segurança, regularização, áreas atendidas, dúvidas frequentes e canais de contato.

A proposta da aplicação é oferecer uma experiência clara, moderna e responsiva, facilitando o acesso às informações principais e incentivando o contato rápido por WhatsApp ou outros meios digitais.

Objetivos
Divulgar o serviço de transporte escolar de forma profissional.

Transmitir confiança, organização e segurança para pais e responsáveis.

Destacar informações importantes sobre o serviço prestado.

Facilitar o contato e a conversão por canais digitais.

Servir como projeto de estudo em React, Tailwind CSS e organização de componentes.
